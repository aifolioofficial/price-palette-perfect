
# Pricing Table Templates

This repository contains a collection of beautiful, responsive pricing table templates that you can use in your web projects. Each template is built with pure HTML, CSS, and a little JavaScript (for the animated version).

## Templates Included

1. **Modern** - Clean and professional pricing tables
2. **Gradient** - Beautiful gradient pricing tables
3. **Card** - Card-based pricing tables
4. **Minimalist** - Clean and simple pricing comparison
5. **Animated** - Dynamic pricing with animations
6. **Simple** - Clean, straightforward pricing
7. **Colorful** - Vibrant, colorful pricing tables
8. **Enterprise** - Detailed enterprise feature comparison

## How to Use

1. Browse the different templates in the main page
2. Choose the style that fits your project
3. Copy the HTML, CSS, and JavaScript (if any) files
4. Customize the content and styles as needed

## Customization

Each template can be easily customized by editing:

- Colors and gradients in the CSS files
- Pricing information and features
- Button text and links
- Adding or removing features as needed

## Responsive Design

All templates are fully responsive and tested across different screen sizes. The layouts automatically adjust to provide optimal viewing experience from desktop down to mobile devices.

## Browser Compatibility

These templates are compatible with all modern browsers:
- Chrome
- Firefox
- Safari
- Edge

## Note on Template Previews

The main index page uses CSS gradients to preview each template style. In a production environment, you might want to replace these with actual screenshots of each design.
